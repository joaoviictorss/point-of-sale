# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Icons

Always use `@heroicons/react` (the `/24/outline` set, matching existing usage like `src/app/(protected)/[organizationSlug]/vendas/_components/sale-receipt.tsx` and `products-list.tsx`). Do not introduce `lucide-react` in new code. If you find `lucide-react` used somewhere, you may swap it for the Heroicons equivalent.
